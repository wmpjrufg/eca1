Nesta disciplina, as memórias de cálculo e demais entregas em texto devem ser
produzidas em **Markdown** (arquivos `.md`). Para editar esses arquivos,
recomenda-se o uso do **Visual Studio Code (VS Code)**, um editor de texto
gratuito com bom suporte a Markdown, tabelas, equações em LaTeX e controle de
versão.

## Instalação do VS Code

1. Acesse a página de download do VS Code:
   [Download VS Code](https://code.visualstudio.com/download?_exp_download=fb315fc982).
2. Selecione o instalador correspondente ao seu sistema operacional (Windows,
   macOS ou Linux) e baixe o arquivo.
3. Execute o instalador e siga as etapas indicadas, mantendo as opções
   padrão sugeridas pelo instalador.
4. Ao final da instalação, abra o VS Code para confirmar que a instalação foi
   concluída com sucesso.

## Instalação da extensão de Markdown

Para visualizar corretamente os arquivos Markdown com equações, tabelas e
figuras, é necessário instalar uma extensão de pré-visualização. Recomenda-se
a extensão **Markdown Preview Enhanced**.

1. Abra o VS Code.
2. Clique no ícone de **Extensões** na barra lateral esquerda (ou use o
   atalho `Ctrl+Shift+X`).
3. Na caixa de busca, digite `Markdown Preview Enhanced`.
4. Clique em **Install** no resultado do autor `Yiyi Wang (shd101wyy)`.
5. Após a instalação, abra um arquivo `.md` e, para visualizar o texto
   formatado, use o atalho `Ctrl+Shift+V` ou clique com o botão direito no
   editor e selecione **Open Preview to the Side**.

```{admonition} Dica
:class: destaque-verde

A extensão Markdown Preview Enhanced também renderiza equações em LaTeX
(como as utilizadas nas aulas desta disciplina), tabelas e figuras
diretamente na pré-visualização, facilitando a conferência da memória de
cálculo antes da entrega.
```
